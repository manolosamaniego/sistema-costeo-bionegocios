# Modulo de Procesos, Capacidad y Planeacion - Fase 5

## Objetivo

Poblar el modulo con datos funcionales de ejemplo y dejar reportes internos listos para demostracion y validacion operativa.

## Familias incluidas

- cacao
- cafe
- aceite esencial
- crema cosmetica
- producto deshidratado

## Lo que cubren los ejemplos

- procesos cortos y de varios dias
- unidades de masa, volumen, conteo y quintal
- conversiones `kg-g`, `kg-qq`, `l-ml`
- recursos compartidos de empaque
- cuellos de botella reales por flujo
- mermas por etapa y mermas totales
- lotes con trazabilidad de entrada y salida
- requerimientos de materiales y envases
- calendario productivo base
- necesidad de bodega

## Reportes internos disponibles

- dashboard operativo
- reporte de capacidad por flujo
- reporte de mermas por lote
- reporte de requerimientos por lote
- reporte de bodega por lote
- reporte de planeacion por lote

## Uso recomendado

1. cargar el seed funcional
2. revisar dashboard y cuellos de botella
3. abrir un lote por familia
4. validar requerimientos, merma y bodega
5. usar el paquete de integracion opcional con costos si hace falta
